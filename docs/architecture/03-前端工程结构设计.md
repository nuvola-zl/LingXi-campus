## 二、实施步骤

1. **项目初始化**：Vite + Vue 3 + TypeScript，安装 pinia、vue-router、element-plus 等依赖，配置 vite.config.ts / tsconfig / env.d.ts，复制基础样式（main.css、base.css）。
2. **核心基础设施**：`utils/auth.ts`（Cookie token 管理）、`utils/apiConfig.ts`（API base URL）、`utils/request.ts`（axios 实例，认证头 + 401 处理）、`utils/sseParser.ts`（SSE 事件解析器）、`stores/user.ts`（Pinia：login / getUserInfo / logout / roleType）。
3. **路由和布局**：完整路由表 + beforeEach 守卫；App.vue 暗色切换 + 全局登录弹窗；PortalHeader / AppSidebar。
4. **API 服务层**：按模块创建 API 文件，统一处理 Result 格式；聊天使用 fetch + ReadableStream 实现 SSE，普通 CRUD 使用 axios。
5. **共享组件**：复用 ChatMessage.vue、LoginDialog.vue、RegisterDialog.vue；新建 ChatInput.vue、ChatSidebar.vue。
6. **聊天视图（IT/HR/Admin）**：三个聊天视图结构相同，domain 参数不同，共用 useStreamingChat composable。
7. **业务视图**：IT（工单列表/详情、知识库管理/问答、工程师面板、服务目录管理）、HR（请假、打卡补正）、Admin（设备申请、会议室预订、审批管理）。
8. **首页入口**：HomePortal.vue 三个大卡片入口，未登录引导登录。

## 三、角色权限控制

- `userStore.roleType`：EMPLOYEE | ENGINEER | ADMIN
- 路由守卫：需要特定角色的路由在 meta 中声明，beforeEach 中校验
- 组件级：`v-if="userStore.roleType === 'ADMIN'"` 控制按钮/菜单可见性
- 侧边栏菜单项通过 computed 过滤掉无权访问的项

## 四、复用策略

- ChatMessage.vue —— 直接复用，包含 Markdown / 思考过程 / 代码高亮 / 图片显示
- LoginDialog.vue / RegisterDialog.vue —— 直接复用
- useStreamingChat.js —— 转为 TypeScript
- SSE 解析逻辑 —— 从旧版 services/api.js 的 parseSSEEvent 提取

## 五、验证方式

1. `npm run dev` 启动开发服务器
2. 登录后进入三个入口，测试 SSE 聊天
3. 验证角色不同时菜单项是否正确隐藏
4. 测试工单创建/查询、请假/打卡提交
5. 验证暗色模式切换
