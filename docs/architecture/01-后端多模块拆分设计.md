# 后端多模块拆分设计

> 项目：Haze-AI-Hub（企业内部 AI 助手平台）
> 主题：单体工程拆分为多模块 Maven 工程的设计方案与落地结果
> 状态：方案已落地（拆分后结构见文末「落地结果」）

## 一、拆分目标

将原有的单体后端工程拆分为四个 Maven 子模块，让依赖方向单向化、职责边界清晰化，为后续接入工单（ITSM）、Skill 框架等业务打基础。

## 二、目标结构

```text

│
```

## 三、模块职责边界

| 模块 | 职责 | 依赖谁 | 被谁依赖 |
| --- | --- | --- | --- |
| ai-common | 纯工具，无 Spring 依赖 | 无 | 所有模块 |
| ai-infrastructure | 技术设施封装 | ai-common | ai-domain, ai-server |
| ai-domain | 实体定义 + 数据访问（Mapper） | ai-common, ai-infrastructure | ai-server |
| ai-server | 业务逻辑 + Skill 框架 + HTTP 入口 | 以上所有 | 无（最顶层） |

## 四、关键设计原则

### 1. ai-domain 只放实体和 Mapper，不放 Service 业务逻辑

```text
❌ 错误：TicketService 放在 ai-domain
✅ 正确：TicketService 放在 ai-server，TicketMapper 放在 ai-domain
```

理由：Service 里要调 AI、要编排 Skill，属于「应用层」，不是「领域层」。

### 2. ai-server 是唯一的 Spring Boot 启动模块

```text
ai-common         → 普通 Maven 模块（jar）
ai-infrastructure → 普通 Maven 模块（jar）
ai-domain         → 普通 Maven 模块（jar）
ai-server         → Spring Boot 模块（可执行 jar）
```

### 3. Skill 框架在 ai-server 里，但只依赖 ai-domain 的实体和 Mapper

```text
ai-server/skill/impl/TicketCreateSkill.java
    → 调 ai-domain/biz/ticket/mapper/TicketMapper.java（查数据库）
    → 调 ai-domain/ai/mapper/KbDocumentMapper.java（查知识库）
    → 调外部 LLM API（生成回复）
```

## 五、落地结果

拆分完成后的实际模块内容与文件规模：

```text
backend/
├── pom.xml (根POM，4个子模块)
├── ai-common/          ← 18个纯Java文件，零Spring依赖
│   └── common/
│       ├── constant/    (8个常量类)
│       ├── context/     (BaseContext)
│       ├── enumeration/ (OperationType)
│       ├── exception/   (BusinessException, ErrorCode)
│       ├── json/        (JacksonObjectMapper)
│       ├── result/      (Result, PageResult)
│       ├── utils/       (JwtUtil, HttpClientUtil, Sha256Util)
│       └── dto/         (预留)
│
├── ai-infrastructure/  ← 9个基础设施文件
│   └── infra/
│       ├── cache/       (CacheUtil - 两级缓存)
│       ├── oss/         (AliOssUtil, AliOssProperties)
│       ├── security/    (JwtProperties)
│       ├── config/      (AstraProperties, ModelProperties, WanxProperties)
│       └── sse/         (预留)
│
├── ai-domain/          ← 实体+Mapper，无Service
│   └── domain/
│       ├── ai/
│       │   ├── entity/  (10个实体类)
│       │   ├── mapper/  (8个Mapper接口)
│       │   ├── dto/     (12个DTO/VO/BO)
│       │   └── vector/  (KbChunkDocumentAdapter)
│       ├── sys/         (entity/mapper/dto 预留 - 用户权限)
│       ├── biz/
│       │   ├── ticket/  (entity/mapper/dto 预留 - 工单)
│       │   └── catalog/ (entity/mapper/dto 预留 - 服务目录)
│       └── handler/     (JsonTypeHandler)
│
└── ai-server/          ← 唯一Spring Boot模块
    └── server/
        ├── skill/       (Skill框架)
        │   ├── core/    (SkillExecutor, SkillContext, SkillResult)
        │   ├── router/  (IntentDetector, SkillRouter)
        │   └── impl/    (KnowledgeQASkill, TicketCreate/Query/UrgentSkill)
        ├── controller/  (8个Controller)
        ├── service/     (14个Service接口+13个实现)
        ├── config/      (12个配置类)
        ├── interceptor/ (JWT拦截器)
        ├── parser/      (文件解析器)
        ├── producer/consumer/ (Redis Stream)
        ├── vector/      (HybridVectorStore)
        └── handler/     (GlobalExceptionHandler)
```
